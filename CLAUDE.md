# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository layout

This repo is a single-app workspace. The Next.js application lives in `ks-multiservices/` — all commands below must be run from that directory, not from the repo root.

`ks-multiservices/CLAUDE.md` re-exports `AGENTS.md`, which contains a Next.js-specific block auto-generated by `next dev` (see `node_modules/next/dist/server/lib/generate-agent-files.js`). That block is expected to reappear on `next dev` — commit it alongside your work rather than trying to strip it.

## Commands (run inside `ks-multiservices/`)

```bash
npm install
npm run dev      # next dev (local development)
npm run build    # next build
npm run start    # next start (serves the production build)
npm run lint     # eslint (flat config, extends next core-web-vitals + typescript)
```

No test runner is configured in `package.json` — do not fabricate a `npm test` invocation.

## Stack

Next.js 16 (App Router) + React 19 + TypeScript (strict) + Tailwind CSS v4 (via `@tailwindcss/postcss`) + GSAP (`@gsap/react`). Path alias `@/*` → `ks-multiservices/src/*`.

This is Next.js 16, not the version most training data covers — for any Next.js API or convention you're unsure about, consult `node_modules/next/dist/docs/` from within `ks-multiservices/` before writing code (see the note in `AGENTS.md`).

## Architecture

**Single-page marketing site.** `src/app/page.tsx` is a client component that renders every section of the homepage in order (Hero → Services → Process → WhyUs → ServiceArea → Gallery → FinalCta), wrapped by `Header`, `Footer`, and a dismissible `IntroSequence` overlay. The intro is a visual layer only — real content is always present in the DOM even without JS.

**Content is centralized.** `src/lib/content.ts` is the single source of truth for every real business fact displayed on the site (phone, address, service categories, gallery items, etc.). Never hardcode business data in components — read it from `content.ts`. The comment at the top of that file states the rule: a missing field stays absent, it is never filled with a plausible-looking value. The `README.md` lists the fields still awaiting real data from the client (gallery photos, legal mentions, contact email, reviews).

**Contact API.** `src/app/api/contact/route.ts` is a Route Handler that validates POSTed contact-form payloads and currently only `console.info`s them — no email/SMS/CRM integration yet. The TODO in that file is intentional; do not swap in a fake provider.

**SEO / structured data.** `src/app/layout.tsx` sets French-locale metadata, loads the Fraunces (display) and Inter (body) fonts as CSS variables, and injects a `HomeAndConstructionBusiness` JSON-LD block built from `business` in `content.ts`. Update the schema there when business facts change.

**Design direction.** Graphite/ink base with a brushed-brass accent (not the default blue/orange); tokens live in `src/app/globals.css`. `src/lib/motion.ts` exposes `prefersReducedMotion()` and a shared `ease.premium` cubic-bezier — use them rather than inlining animation timings.
